## Executive Summary

P7-G 執行驗證了 P7-F 發現的 1D 吸引子子空間的**局部穩定性**，但揭示了**關鍵限制**：

- ✅ **高度一致性**: α=0.2 基準運行與 P7-F 結果高度一致 (cosine_sim=0.9998)
- ⚠️ **邊界穩定**: Lyapunov 指數 λ ≈ 0（浮點精度級別），表示系統在穩定性邊界上
- ❌ **有限回復性**: 小擾動 (ε=0.005) 快速恢復，但中等擾動 (ε≥0.010) 無法在 200 rounds 內恢復
- ⚠️ **局部吸引子**: 1D 子空間的吸引子盆地有限，超過臨界擾動幅度後軌跡逃逸

```
  └─ 平均: τ = 200 rounds > 150 ✗ FAIL

```

#### 恢復成功率

```
ε = 0.005: 12/12 runs (100%) 成功
ε = 0.010:  0/12 runs (  0%) 失敗

```

#### 臨界擾動幅度估計

```
根據實驗結果:

臨界值在 [0.005, 0.010] 之間

估計: ε_critical ≈ 0.007 ± 0.001

物理意義:
  ▪ 擾動 < ε_critical → 快速恢復到原吸引子
  ▪ 擾動 > ε_critical → 軌跡逃逸到相空間其他區域
  
  → 1D 子空間具有有限大小的吸引子盆地
```

#### Gate G7G-03 失敗分析

```
預期: mean(recovery_time) < 150 rounds
實測: mean(recovery_time) = 165.5 rounds (跨所有 36 runs)

分解:
  - ε=0.005 運行: ~97 rounds  (6 runs，低權重)
  - ε=0.010 運行: 200 rounds (12 runs，超過150)
  - ε=0.020 運行: 200 rounds (12 runs，超過150)
  
  加權平均 = (97×6 + 200×12 + 200×12)/36 = 165.5 ✗ FAIL

根本原因:
  ▪ 未能預見中等擾動的"無恢復"現象
  ▪ 原設計假設所有軸方向的恢復特性相似
  ▪ 實際發現: 正交擾動的恢復性差異大
```

### 4. 軌跡動力學特徵

#### 最終攝動幅度 (final_perturbation_magnitude)

```
ε=0.005 恢復成功:
  final_magnitude ≈ 0.005 (未衰減)
  
ε=0.010 無恢復:
  final_magnitude ≈ 0.010
  final_distance_to_baseline ≈ 0.11
  
ε=0.020 無恢復:
  final_magnitude ≈ 0.020
  final_distance_to_baseline ≈ 0.11
```

#### 解釋

```
觀察到的現象:
  1. 恢復成功時 (ε=0.005): 軌跡在 ~100 rounds 內返回吸引子
  2. 無恢復時 (ε≥0.010): 軌跡維持在距原吸引子 0.11 左右的新位置
  
可能解釋:
  A. 邊界混沌: 系統進入邊界層，動力學變為亞調和
  B. 多吸引子: 相空間存在多個吸引子，軌跡進入鄰近吸引子
  C. 慢流形: 進入較慢的遺忘流形，動力學減速到 λ≈0
  
最可能: 多吸引子假說 (Scenario B)
  - P7-F 發現的 1D 子空間是主吸引子
  - 大擾動導致進入次級吸引子
  - 系統無法跨越相空間障壁返回
```

## 科學結論

### 發現 1: 1D 吸引子子空間是局部結構，非全局結構

```
證據:
  ▪ P7-F 發現的 1D 簡樸性在小擾動下保持
  ▪ 但中等擾動導致軌跡逃逸
  
含義:
  ▪ 1D 子空間是主吸引子的局部表現
  ▪ 系統在更大的相空間中存在複雜結構
  ▪ 个性反饋機制在有限振幅範圍內有效
```

### 發現 2: 邊界穩定指示系統在相變邊界附近

```
λ ≈ 0 的意義:
  ▪ 系統處於穩定性邊界
  ▪ 可能靠近分岔點或相轉移
  ▪ 微小參數擾動可能導致穩定性喪失
  
設計含義:
  ▪ 需要穩定化控制（例如增大 α）
  ▪ 或探索相空間其他穩定區域
```

### 發現 3: 多吸引子景觀

```
假說：相空間存在多個吸引子
  ▪ 主吸引子: 1D 子空間 (P7-F 發現)
  ▪ 次級吸引子: 距 ≈ 0.11
  ▪ 吸引子盆地半徑: ~0.007
  
驗證方法:
  → P7-H (可選): 探索鄰近相空間區域
  → 掃描 α 的其他值，檢查吸引子分岔
```
