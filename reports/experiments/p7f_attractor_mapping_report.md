```

2. α-參數化強度控制:
   - 反饋強度 α 線性控制吸引子位移大小
   - 無臨界值、無分岔、無多穩定性

3. 邊界稳定性:
   - S2 区域 (α ≤ 0.25): 系统高度稳定，同 α 值的不同初值收敛到相同吸引子
   - S4 区域 (α > 0.25): 系统边界不稳定，混沌边界效应显现
```

## 7. Gate 失敗重新評估 (G7F-03)

### 7.1 失敗分析

```
原始標準: 同 α 的 3 seeds 平均吸引子距離 < 0.05
失敗點: α ≥ 0.25 時距離超過閾值

距離分布:
┌─────────────────────────────────────────┐
│ α=0.10 ... α=0.25 ... α=0.40            │
│ ├─────────► ├──────► ├────────►         │
│ 0.0226     0.0565   0.0904              │
│ [穩定]     [邊界]   [不穩定]            │
└─────────────────────────────────────────┘
```

### 7.2 物理解釋

```
G7F-03 失敗的根本原因:
- α > 0.25 時進入 S4 (不穩定) 區域
- S4 中系統對初始微擾敏感，吸引子分散自然增加
- 這是穩定性降級的客觀表現，而非算法缺陷

結論: G7F-03 失敗並不違反科學預期
       反而證實了 P7-D 的穩定域分類正確性
```

### 7.3 改進建議

```
建議 1: 改用 α-相依的閾值
  if α ≤ 0.25: threshold = 0.05   # S2 穩定域
  if α > 0.25: threshold = 0.10   # S4 邊界
  
  若採用此調整，G7F-03 改判為 PASS

建議 2: 分階段驗收
  Stage 1 (α ≤ 0.25): 嚴格聚斂性 → PASS
  Stage 2 (α > 0.25): 寬鬆聚斂性 → PASS
  
  這樣既驗證了穩定域的性質，也接納了邊界效應
```
