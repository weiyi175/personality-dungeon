# P7-H 吸引子相空間全景探索

**版本**: v1.0 Design  
**日期**: 2025-06-04  
**目標**: 繪製 9D 人格空間在 (v₁, v₂) 2D 平面上的吸引子景觀（Landscape）  
**科學目的**: 
1. 精確定位次級吸引子（距離 ≈ 0.11）
2. 繪製吸引子盆地邊界（Separatrix）
3. 計算全譜 Lyapunov 指數（9D 完整光譜）
4. 評估系統混沌性和可控性

## 核心發現（基於 P7-F SVD）

### 主軸特徵解析

#### 軸 1：主演化軸 (v₁, σ₁ = 9.195, 99.93% 方差)

```
正向端點：風險厭惡 (+0.460)
負向端點：好奇心 (-0.409), 衝動性 (-0.385)

人格演化箭頭：
  弱反饋 (α < 0.2) 
    ↓
  好奇心 & 衝動性 驅動的冒險者
    ↓
  強反饋 (α > 0.3)
    ↓
  風險厭惡 & 謹慎的保守者

物理含義：
  這條軸是系統在面對獎懲時的主要適應方向。
  代表個體如何在「探索」和「開發」之間平衡。
```

#### 軸 2：次要擾動軸 (v₂, σ₂ = 0.235, 0.06% 方差)

```
正向端點：風險厭惡 (+0.253)
負向端點：懷疑性 (-0.706), 耐力 (-0.465)

人格變化軌跡：
  高懷疑性 → 失去耐力的易挫折者
  vs
  低懷疑性 → 具有韌性的相信者

物理含義：
  副作用軸。反映在極端反饋下，信任和韌性的喪失。
  當系統偏離主軸時，懷疑性增加會導致行為崩潰。
```

## 實驗設計：2D 細胞映射法

### Phase 1：基準 2D 網格掃描 (1,681 點)

```yaml
掃描配置:
  初始點: P₀ = P*(α=0.2) 
          (P7-F 基準吸引子，每個特徵的平均值)
  
  擾動方向 1 (軸 1): 沿 v₁ 
    範圍: [-0.020, +0.020]
    步長: 0.001
    點數: 41
  
  擾動方向 2 (軸 2): 沿 v₂
    範圍: [-0.020, +0.020]  
    步長: 0.001
    點數: 41
  
  網格點總數: 41 × 41 = 1,681 點
  
每個網格點 (i, j):
  起點: P(i, j) = P₀ + 0.001×(i-20)×v₁ + 0.001×(j-20)×v₂
  
  執行: 200 rounds 模擬
  
  終點分類:
    A) 主吸引子盆地:  ||終點 - P₀|| < 0.010
    B) 次級吸引子:   0.100 < ||終點 - P₀|| < 0.120
    C) 遠離區域:     ||終點 - P₀|| > 0.150
    D) 混沌/未分類:  其他
```

### Phase 2：邊界精細掃描 (高精度)

基於 Phase 1 結果，在吸引子盆地邊界附近進行精細掃描：

```yaml
目標: 精確定位 ε_critical ≈ 0.007 的盆地邊界
      
掃描策略:
  邊界網格步長: 0.0005 (更細)
  邊界鄰域寬度: ±0.002
  
預期產出: 邊界的微觀拓撲結構
```

### Phase 3：全譜 Lyapunov 指數計算 (選定點)

對每個 2D 網格點，計算完整的 9D Lyapunov 譜 {λ₁, λ₂, ..., λ₉}：

```yaml
方法: QR 分解法 (Gold Standard for Lyapunov Spectra)

算法:
  1. 初始化：Jacobian 矩陣 J ∈ ℝ^(9×9)
  2. 遍歷 200 rounds：
     a) 計算當前步的 DF(x)（動力系統 F 的導數）
     b) J ← DF(x) · J
     c) 執行 QR 分解：J = Q · R
     d) 更新 J ← Q (保留酉矩陣部分)
     e) 累積 λᵢ ← (1/T) Σ log|R_{ii}|
  
  3. 結果：{λ₁ ≥ λ₂ ≥ ... ≥ λ₉}

掃描點集合:
  - P₀ (主吸引子) 及其鄰近點 (3×3 網格)
  - 次級吸引子及其鄰近點 (3×3 網格)
  - 邊界上的代表點 (5 個)
  
總計: ~20 個選定點
```

### Phase 4：數值延拓法 (可選，高級)

追蹤隨 α 變化時吸引子的移動軌跡和分岔點：

```yaml
方法: Pseudo-arclength Continuation

掃描: α ∈ [0.2, 0.4], Δα = 0.01

對每個 α:
  1. 找到該 α 下的固定點 P*(α)
  2. 計算 Jacobian，估計穩定性
  3. 追蹤固定點的移動
  
預期發現:
  - 分岔點位置 (saddle-node? transcritical? pitchfork?)
  - 固定點的穩定性變化
  - 吸引子族的拓撲轉移
```

## 期望科學發現

### Scenario A：穩定次級吸引子（最可能）

```
特徵:
  ✓ 次級吸引子確實存在，距主吸引子 ≈ 0.11
  ✓ 次級吸引子具有吸引性（λ_max < 0）
  ✓ 主吸引子盆地是一個明確的半徑 ≈ 0.007 的球
  ✓ 盆地邊界光滑（Separatrix 是簡單曲線）

物理含義:
  系統具有雙吸引子結構，代表「冒險型」和「保守型」
  的兩種穩定個性狀態。超過臨界擾動時，個體轉換狀態。

應用價值:
  高度！可用於設計多穩定個性系統。
```

### Scenario B：邊界混沌（邊界穩定的內在原因）

```
特徵:
  ⚠️ 盆地邊界附近存在混沌吸引子（Chaotic Attractor）
  ⚠️ 因此 λ_max ≈ 0 是多個正負 Lyapunov 指數相互抵消
  ⚠️ 在極端擾動下，軌跡陷入邊界混沌狀態

物理含義:
  系統在邊界上存在「無序性」，但整體是穩定的。
  這解釋了為何 G7G-04 失敗（λ ≈ 0）。

應用價值:
  需要增加控制增益以遠離混沌邊界。
```

### Scenario C：高維次調和分岔（複雜）

```
特徵:
  ⚠️ 軌跡進入複雜的次調和運動（subharmonic）
  ⚠️ 非周期軌跡，但有特定的相空間結構
  ⚠️ 無簡單的「次級吸引子」

物理含義:
  系統行為比預期複雜，需要進一步分析。
  
應用價值:
  深度研究，短期應用有限。
```

## 科學嚴謹性檢查清單

- [ ] 2D 投影的合理性（v₁ + v₂ 是否足以代表系統動力學？）
  - 檢驗：計算軌跡偏離 (v₁, v₂) 平面的距離
  - 預期：軌跡保留在平面内 ±0.05 以內

- [ ] 初始條件敏感性（種子 42 vs 43 vs 44 的網格掃描結果是否一致？）
  - 檢驗：Phase 1 選 3 個種子重複
  - 預期：盆地邊界位置誤差 < 0.002

- [ ] 邊界精細掃描的充分性（Δε = 0.0005 足否？）
  - 檢驗：邊界上任意兩相鄰點的分類是否一致
  - 預期：邊界銳化後，相鄰點分類轉移清晰

- [ ] Lyapunov 譜的數值穩定性（QR 算法的精度）
  - 檢驗：用兩種獨立方法計算 λ₁（比如 QR vs Oseledets）
  - 預期：結果一致到小數點後 3 位

## 決策標準：何時停止 P7-H？

- ✓ **STOP** 如果發現：
  - 穩定的次級吸引子（可解釋，可應用）
  - 清晰的盆地邊界結構
  - 完整的 Lyapunov 譜（包括負指數）
  - 分岔點明確定位
  
- 🔄 **CONTINUE to P7-I** 如果發現：
  - 高維混沌（維度 > 3）
  - 多重吸引子（> 2 個）
  - 複雜的邊界（碎形特性）
  - 需要參數優化以改善穩定性
